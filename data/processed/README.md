# Processed data

Generated by the numbered scripts in `scripts/`. Not tracked in git — run
the pipeline in order to reproduce.

- `metadata.csv` — sample-level table (sample_id, group, patient_id, condition)
  for the clean 80-sample AD/CTRL cohort. Produced by
  `scripts/curate_subset.py`.
- `counts_subset.csv` — gene x sample raw count matrix, subset to the same
  80 samples. Produced by `scripts/curate_subset.py`.
